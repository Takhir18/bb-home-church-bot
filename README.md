# Божья Благодать — Домашние церкви

Рабочая MVP-версия Telegram-бота + Mini App.

## Что уже работает
- `/start` в Telegram с кнопкой открытия Mini App
- список домашних церквей
- поиск и фильтры
- реальные названия, лидеры, районы, время, возраст и размер групп
- реальные изображения лидеров из предоставленных материалов
- экран "Что такое домашняя церковь"
- карточка группы
- кнопка маршрута в Яндекс Картах
- заявка "Хочу прийти"
- сохранение заявок в SQLite
- опциональная отправка заявки администратору в Telegram

## Быстрый запуск локально
1. Установите Python 3.11+
2. В папке проекта:
   python -m venv .venv
3. Активируйте окружение.
4. pip install -r requirements.txt
5. Скопируйте `.env.example` в `.env`
6. Для просмотра Mini App:
   uvicorn app.server:app --reload --host 0.0.0.0 --port 8000
7. Откройте http://localhost:8000

## Запуск в Telegram
Telegram Mini App требует публичный HTTPS URL.
1. Создайте бота через @BotFather и получите токен.
2. Разместите этот проект на сервере/Render/Railway/VPS.
3. В `.env` задайте:
   BOT_TOKEN=...
   WEBAPP_URL=https://ваш-домен
   ADMIN_CHAT_ID=...  (необязательно)
4. Запустите web:
   uvicorn app.server:app --host 0.0.0.0 --port 8000
5. Во втором процессе:
   python bot.py

## Важно
Точные домашние адреса не показываются в общем списке. Они используются только для маршрута.
Телефонные номера лидеров намеренно не опубликованы в Mini App.
Telegram usernames лидеров можно добавить позже.
